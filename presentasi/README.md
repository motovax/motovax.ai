# Presentasi Vax Family

Deck marketing untuk penjualan Motovax dan pengenalan Terravax.

## Cara memakai

1. Jalankan situs dengan `npm run dev`.
2. Buka `http://localhost:5179/presentasi/vax-family.html`.
3. Navigasi dengan tombol panah, `Space`, `Page Up`, atau `Page Down`.
4. Klik **PDF**, lalu pilih **Save as PDF**, layout landscape, margin none, dan aktifkan background graphics.

Versi PDF siap kirim tersedia di `vax-family-sales-deck.pdf`.

## Positioning dan guardrail

- Motovax M1 Agentic AI ditawarkan sebagai produk utama yang tersedia sekarang.
- Fitur live yang disebutkan mengacu ke route, tools, flag tenant, dan dokumentasi `motovax-app`.
- Terravax ditandai **early access / roadmap vertical**, bukan produk live penuh.
- Statistik eksternal selalu menyertakan tahun, sumber, dan konteks geografi.
- Target pilot harus ditetapkan sesudah baseline pelanggan; jangan menjanjikan uplift generik.
